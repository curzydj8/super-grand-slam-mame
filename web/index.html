玩法说明与按键表
  1. 点「投币」再点「开始」进入游戏（街机流程）。
  2. 手机直接用手指点下面的麻将按键；电脑用鼠标点击，或用键盘。
  3. 「按键设置」可以把每个按钮重绑到任意键盘按键（需要物理键盘，手机上请用默认键位）。
  4. 如果按键没反应：点模拟器画面右上角菜单 → Quick Menu → Options → 把 Input Interface 设为 simultaneous 或 keyboard。
  5. 模拟器自带存档：画面菜单 → Save State / Load State。
